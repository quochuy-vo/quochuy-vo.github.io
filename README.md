# Academic Personal Webpage - Quoc-Huy Vo

Personal academic webpage for **Quoc-Huy Vo (Võ Quốc Huy)**, Ph.D. Candidate at SOKENDAI (The Graduate University for Advanced Studies) & National Institute of Informatics (NII), Tokyo, Japan.

Live website: [https://quochuy-vo.github.io/](https://quochuy-vo.github.io/)

## Research Areas
- **Cloud Computing & IaC Security**: Terraform code smell detection, static analysis, and LLM fine-tuning.
- **Web Privacy & Security**: Large-scale measurement of PII leakage via Single Sign-On (SSO) authentication.
- **Systems & Cloud Infrastructure**: Microservices, Docker orchestration, and CI/CD pipelines.

## Features
- **Modern Academic Design**: Clean typography, high readability, and responsive layout.
- **Interactive Publications**: Category filtering, direct links, and one-click BibTeX copy drawers.
- **Dark & Light Mode**: Persistent theme toggle respecting system preferences.
- **Print Friendly**: Optimized CSS for clean printing.
- **Zero Heavy Dependencies**: Pure semantic HTML5, modern CSS3, and lightweight vanilla JavaScript.
